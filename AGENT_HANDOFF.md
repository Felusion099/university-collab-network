# AGENT_HANDOFF.md

## Protocol (read this first, every session)
1. Read `PROJECT_SPEC.md`, `ARCHITECTURE.md`, `FILE_STRUCTURE.md`, `API_CONTRACT.md`, `DATABASE_SCHEMA.md`, `IMPLEMENTATION_STATUS.md`, this file, `DECISIONS.md`, in that order.
2. Determine current phase from `IMPLEMENTATION_STATUS.md`.
3. Do not write code until the above is understood.
4. Before coding, report: `CURRENT PHASE / CURRENT PROJECT STATE / WHAT ALREADY EXISTS / FILES TO MODIFY / FILES NOT TO MODIFY / DEPENDENCIES / RISKS / IMPLEMENTATION PLAN`.
5. Implement only your phase's owned files. If you need to touch another phase's files, stop and add an entry below instead.
6. Run syntax/type/lint/test/build checks relevant to what you changed. Fix what you broke. Don't hide failures.
7. Before ending the session, update `IMPLEMENTATION_STATUS.md` (mark phase status, list evidence) and this file (clear resolved handoff items, add new ones).
