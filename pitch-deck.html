Security

Authorization lives on the server.

🔐
Passwords
bcrypt-hashed — one-way, salted. The hash never appears in any API response (regression-tested).
🎫
Sessions
15-min JWT access token + 7-day refresh in an httpOnly cookie — JavaScript can't steal it.
🛡️
Server-side checks
Owner-only edit/delete, recipient-only accept, connected-only messaging, admin-only panel — all verified against the database.
🕵️
Privacy
Per-field visibility (public / university / connections / private) — private data never leaves the DB for unauthorized viewers.
Anti-Spam + Trust

Professional-networking rules, enforced.

3️⃣
Rate limit
Max 3 connection requests per week to the same person — server-side; cancel-and-resend counts. 4th attempt → 429.
🔗
Connect to message
No connection → no direct messaging. Enforced with 403s, not hidden buttons.
👑
Rank hierarchy
Nobody removes, edits or demotes someone at-or-above their own rank. Presidents transfer, not abandon.
